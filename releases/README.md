# Central

[BF4 Central 0.5.34](BF4-Central-0.5.34.zip) — versão mais recente: executável para Windows x64 (chat dos bots em português com resumo da partida, votação, denúncias e [TIME]). Sem arquivos do jogo, mod, banner ou miniaturas de terceiros. Extraia o ZIP e execute `BF4 Central.exe` como administrador. Requer BF4 e mod compatível instalados separadamente; a liberação é por compra via Pix no Sócio Premiado.
