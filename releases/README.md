# Instalador da Central

[BF4 Central Setup 0.4.2](BF4-Central-Setup-0.4.2.zip) — aplicativo para Windows x64, sem arquivos do jogo, mod, banner ou miniaturas de terceiros. Extraia o ZIP e execute o instalador. Requer BF4 e mod compatível instalados separadamente. Consulte [distribuição](../docs/DISTRIBUICAO.md) e [SHA-256](SHA256.txt).
