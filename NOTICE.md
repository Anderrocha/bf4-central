# Conteúdo deste repositório

Código da Central desenvolvido durante este projeto. Não contém executáveis, DLLs, mapas, navegação, dados de conta ou arquivos de configuração reais do jogo. Battlefield e os nomes dos mapas identificam a compatibilidade do aplicativo; não há afiliação declarada com a EA ou com os autores dos componentes auxiliares.

Os comandos RCON foram consultados na documentação do próprio projeto [vu-rcon](https://multivit4min.github.io/vu-rcon/classes/battlefield.html). A implementação C# do cliente está neste repositório. Nenhuma licença de código aberto foi escolhida para esta importação.
